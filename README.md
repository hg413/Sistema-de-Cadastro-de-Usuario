# Sistema de Cadastro de Usuários

Aplicação web simples para gerenciamento de usuários, desenvolvida como prática/desafio técnico.  
O sistema permite realizar operações básicas de **CRUD** (Create, Read, Update e Delete), possibilitando o cadastro, listagem, edição e exclusão de usuários.

A aplicação foi construída utilizando apenas **HTML, CSS e JavaScript puro**, sem uso de banco de dados ou frameworks back-end, utilizando o **LocalStorage** do navegador para persistência dos dados.

---

## 🚀 Funcionalidades

- 📋 Listagem de usuários cadastrados  
- ➕ Cadastro de novos usuários  
- ✏️ Edição de usuários existentes  
- 🗑️ Exclusão de usuários  
- 💾 Persistência de dados com LocalStorage  

---

## 🧑‍💻 Dados do Usuário

Cada usuário possui os seguintes dados:  

- Nome  
- E-mail  
- Telefone  

---

## 🛠️ Tecnologias Utilizadas

- HTML5 (`index.html`)  
- CSS3 (`style.css`)  
- JavaScript (Vanilla JS) (`script.js`)  
- LocalStorage
